# Ryan McDonald - Cybersecurity Lab Portfolio

This repository contains selected cybersecurity labs completed as part of my coursework at Augusta University. I reorganized the original assignments into project-style writeups so the repository focuses on the security skills demonstrated rather than the assignment instructions.

## Projects

| Project | Main Focus |
|---|---|
| [Vulnerability Scanning with Greenbone](01-vulnerability-scanning-greenbone/) | Vulnerability scanning and result review |
| [Web Application Security Testing](02-web-application-security/) | Nikto, Burp Suite, DVWA, and SQL injection concepts |
| [Man-in-the-Middle Network Lab](03-mitm-network-analysis/) | Network interception concepts and traffic analysis |
| [Client-Side and Social Engineering Labs](04-client-side-and-social-engineering/) | BeEF, SET, browser security, and user-focused attack paths |
| [Armitage Exploitation Lab](05-armitage-exploitation/) | Controlled exploitation and basic post-access review |
| [Incident Response Scenario](06-incident-response/) | Detection, containment, evidence, and recovery planning |
| [Network Security Fundamentals](07-network-security-fundamentals/) | Network configuration, connectivity, and basic reconnaissance |
