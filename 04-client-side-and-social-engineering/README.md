# Client-Side and Social Engineering Security Labs

## Overview
This project combines controlled labs that demonstrated client-side exploitation concepts and social engineering tooling. The goal was to understand how attackers may target users and browsers so defenders can recognize and reduce that risk.

## What I Did
- Used BeEF in a controlled lab to observe browser hooking and client-side behavior.
- Worked through a Social-Engineer Toolkit exercise in an isolated training environment.
- Reviewed how user interaction can become part of an attack path.

## Tools and Concepts
- BeEF
- Social-Engineer Toolkit (SET)
- Client-side security
- Social engineering awareness

## What I Learned
Technical controls alone are not enough when an attack targets a user's browser or actions. User awareness, browser security, endpoint protection, and limiting unnecessary access all help reduce exposure.
