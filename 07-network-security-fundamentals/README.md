# Network Security Fundamentals Labs

## Overview
This project collects several early CYBR-3100 labs focused on network command-line work, host information, connectivity checks, and basic security testing in an isolated environment.

## What I Did
- Used command-line tools to review local network configuration.
- Tested connectivity between assigned lab systems.
- Observed host and network information during guided security exercises.
- Practiced basic reconnaissance concepts in a controlled environment.

## Tools and Concepts
- Windows and Linux command line
- Network configuration review
- Connectivity testing
- Basic host reconnaissance

## What I Learned
Before investigating a security problem, it is important to understand the system's network configuration and confirm how hosts communicate. These fundamentals support later work in vulnerability scanning, incident response, and network defense.
