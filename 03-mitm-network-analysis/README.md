# Man-in-the-Middle Network Lab

## Overview
This project documents a controlled man-in-the-middle lab completed for CYBR-3100. The exercise focused on observing network behavior and understanding how traffic can be intercepted when a network is not properly protected.

## What I Did
- Followed a controlled lab scenario involving traffic interception.
- Observed command-line network activity during the exercise.
- Reviewed captured network information as part of the lab workflow.

## Tools and Concepts
- Network traffic analysis
- Man-in-the-middle concepts
- Linux command line
- Packet and host information review

## What I Learned
A man-in-the-middle attack is dangerous because an attacker can place themselves between systems and observe or alter traffic. Strong encryption, secure network design, and proper certificate validation reduce this risk.
