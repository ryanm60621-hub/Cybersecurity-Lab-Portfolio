# Web Application Security Testing

## Overview
This project combines several controlled web security labs. The work included vulnerability scanning of a web server, password testing against a lab web application, and SQL injection testing in DVWA.

## What I Did
- Used Nikto to scan a lab web server for common web weaknesses.
- Used Burp Suite Intruder in a controlled exercise to test web application login behavior.
- Practiced SQL injection concepts against DVWA, an intentionally vulnerable training application.
- Reviewed application responses to understand how unsafe input handling can expose data.

## Tools and Concepts
- Nikto
- Burp Suite Intruder
- DVWA
- SQL injection
- Web application testing

## What I Learned
Web application security depends heavily on how input is handled and how authentication is protected. These labs showed how automated testing and manual testing can expose weaknesses that developers and defenders need to recognize.
